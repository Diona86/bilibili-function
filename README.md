# 网页视频下载与 B 站笔记

桌面 Chrome 扩展，可下载普通网页和嵌入式播放器中的视频。在 B 站视频页，还可以结合当前分 P 的音频和画面生成可跳转到原片的学习笔记。

## 安装

1. 在 Chrome 116 或更新版本打开 `chrome://extensions/`，开启「开发者模式」。
2. 点击「加载已解压的扩展程序」，选择本项目目录（包含 `manifest.json`）。
3. 打开视频所在网页，在浏览器工具栏的拼图菜单里点「网页视频下载与 B 站笔记」。

## 下载视频

打开目标网页，点一次工具栏中的扩展图标，再播放几秒。在侧栏点「查找网页视频」，选择播放器或媒体文件。侧栏会继续跟踪该页中新出现的播放器和媒体请求。跨域嵌入页可点「允许读取播放器」授权对应域名，也可直接打开播放器网页。

- **直链文件**支持 MP4、M4V、MOV、WebM、MKV 和 Ogg/Theora（OGV）。支持查询参数、重定向和带媒体响应头的无后缀地址。扩展校验文件后原样保存。MKV 和 OGV 在 Chrome 中能否播放取决于容器内的编码和浏览器版本。
- **HLS 点播**支持主清单、媒体清单、多画质、MPEG-TS、fMP4、固定初始化段、连续字节范围和外部音频。选择画质后，侧栏会列出该画质关联的音轨和字幕。
- **DASH 点播**支持常见单 Period 静态 MPD、Representation、SegmentTemplate、SegmentTimeline、初始化分片，以及解析器可展开的分段列表。可选视频和独立音轨。依赖外部索引且没有完整独立媒体文件的结构可能无法下载。
- **无损合并**保留原始编码，自动模式优先 MP4，也可指定 WebM 或 MKV。可用容器由实际音视频编码决定。保存前会重新读取输出，检查轨道、首尾媒体包和时长。
- **字幕**可从播放器或清单选择 WebVTT、SRT 并单独保存。分段 WebVTT 仅在时间映射一致、时间轴可保留时拼接。单文件保留原始字幕字节。
- **B 站分 P**在原视频页选好分 P 和清晰度，播放几秒，点「下载当前分 P」。扩展按当前 CID 选择直链或独立音视频，文件名包含 P 序号。

### 队列与历史

最多同时准备两个任务。可关闭侧栏，准备期间须保留原视频页。队列会显示已读字节或分片数，有足够数据时显示速度和剩余时间。等待中的任务、分段下载和 Chrome 可暂停的保存操作支持暂停。取消后可在历史中重试，未交给 Chrome 保存的任务会从头读取。

下载历史在本机保留最近 40 个已结束任务。后台工作线程唤醒后会重新连接执行中的任务，或核对 Chrome 下载记录。关闭浏览器会使原页面、Blob 和临时地址失效；需要时请回到原页重新识别。只有 Chrome 已完成保存并通过结果检查，任务才显示「已完成」。

### 识别范围

识别 HTML5 视频、动态插入的播放器、开放的 Shadow DOM、获得授权的 iframe、播放器元数据和正常播放产生的媒体响应。Blob 文件可以验证和下载。MSE 播放器依赖可识别的真实清单或文件，单独的媒体分片不会列为视频。网页播放器明确禁止下载、加密或 DRM、直播、多时段 DASH、HLS 时间线切换、无法读取的跨域流、封装字幕均有相应限制。大文件的可处理规模取决于浏览器可用内存和 Blob 存储。

媒体检测与下载在浏览器内执行，无需模型或 API Key。扩展仅为用户启用的标签页保留有限的媒体响应元数据，不保存请求头或 Cookie。跨域直链可按需授权访问对应域名，该模式不携带登录凭据。临时媒体 URL 仅存于当前会话。下载使用随包分发的 Mediabunny 1.66.2 和 mpd-parser 1.4.1。[Mediabunny 许可证](vendor/Mediabunny-LICENSE.txt) · [mpd-parser 许可证](vendor/mpd-parser-LICENSE.txt)

### 测试与构建

开发环境使用 Node.js 24、npm 和 Python 3。首次执行 `npm ci` 和 `npx playwright-core install chromium`。也可用 `CHROMIUM_PATH` 指向支持扩展调试的 Chromium。运行 `npm run typecheck` 检查媒体模块及其依赖，`npm test` 运行解析器、真实文件和 Chromium 侧栏下载测试，`npm run build` 在项目根目录生成带版本号的安装 ZIP。解压后按上面的安装步骤加载。

测试样本是用 FFmpeg 生成的图案、正弦音和原创字幕，已随源码提供。需要重建样本时执行 `python tests/make_fixtures.py <ffmpeg 路径>`。安装包仅包含运行时文件、说明和许可证。

## 生成 B 站学习笔记

1. 在「模型设置」里填 DeepSeek 官方地址 `https://api.deepseek.com`，选择 `deepseek-flash` 并填写 API Key。可以继续使用已保存的配置。[DeepSeek 语音识别](https://api-docs.deepseek.com/zh-cn/guides/asr/) · [DeepSeek 图像输入](https://api-docs.deepseek.com/guides/vision/)
2. 打开并播放当前分 P 几秒，点「生成学习笔记」。默认从网页的播放请求定位当前分 P 的独立音轨并下载。需要网页已加载可下载的音轨。也可选与当前分 P 对应的本地音视频文件、授权音轨直链，或让当前播放器从头静音播放到片尾。
3. 开始后可以切换到其他标签页。扩展准备音轨和画面时，保留原视频页和侧栏。侧栏显示「后台生成」后，可以离开原视频页或关闭侧栏，恢复侧栏就能查看进度和笔记。
4. 扩展每 45 秒切分一段音频并提交转写，从原片最多抽取 12 张画面，再把两种资料按时间一起交给模型。采集结束后，扩展会恢复同一视频的播放位置和状态。
5. 点击笔记里的时间会回到任务对应的分 P。转写引用跳到该段起点，画面引用跳到取帧时刻。可展开原文或画面，也可复制 Markdown 笔记。

遇到笔记回复空白、截断或格式异常时，扩展会自动重试对应的一次整理请求。若整理仍失败，可以在本次 Chrome 会话内点「重试整理笔记」，复用已完成的转写和画面。

DeepSeek 语音识别按送出的音频时长计费，笔记生成按模型用量计费。在 Chrome 的扩展管理页面点「重新加载」可更新本地代码，原有模型设置会继续使用。
